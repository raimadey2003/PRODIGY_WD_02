# ⏱️ Stopwatch Web Application

A feature-rich and visually appealing **Stopwatch Web Application** developed using **HTML**, **CSS**, and **JavaScript** as part of my **Web Development Internship at Prodigy InfoTech**.

---

## 🚀 Features

- Start, Pause, Reset, and Lap time tracking
- Live time display with real-time updates
- Elegant UI with glowing neon styling
- Rhombus-shaped glitter animations across the background
- Autoplay video embedded on the left (30% width of the page)
- Fully responsive and user-friendly layout

---

## 🧠 What I Learned

- DOM manipulation and JavaScript event handling  
- Structuring responsive UIs with HTML and CSS  
- Time-based function implementation (start, pause, reset, lap)  
- Multimedia integration using HTML `<video>`  
- Advanced styling with CSS animations and glowing effects  

---


## 💻 Tech Stack

- **HTML** – Page structure  
- **CSS** – Styling, layout, animations  
- **JavaScript** – Stopwatch functionality and dynamic behavior
